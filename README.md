## How To Run

This is a C program. Use any computer that runs C since like the ANSI days.

With gcc,

```
gcc main.c && ./a.out
```

Maybe you're feeling dangerous and want to use clang. In that case,

```
clang main.c && ./a.out
```

And that's that!
